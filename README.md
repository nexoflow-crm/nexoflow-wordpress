# NexoFlow for WordPress

Publish NexoFlow articles to a WordPress site. The plugin pulls jobs over HTTPS and creates or updates posts locally. NexoFlow does not need inbound access to your REST API.

## Install

Download `nexoflow.zip` from [Releases](https://github.com/nexoflow-crm/nexoflow-wordpress/releases), then in WordPress go to **Plugins → Add New → Upload Plugin**.

1. Activate **NexoFlow**.
2. Open **NexoFlow** in the admin sidebar.
3. Paste the site connect key from your NexoFlow WordPress project and click **Save**.

Save tests the connection. Use **Test connection** or **Sync now** later as needed.

## What it writes

Posts, categories, tags, featured images, and SEO-optimized title, meta description, and focus keyword for every article (Yoast, Rank Math, AIOSEO).

## Requirements

- WordPress 6.0 or later
- PHP 7.4 or later
